# 共有AWSの設計

```text
Flutter → HTTPS → CloudFront + WAF
                       ↓ OAC / SigV4
                Lambda URL (AWS_IAM)
                       ↓ Mangum / FastAPI
                アプリトークン・入力検証
                       ↓
                DynamoDBで日次回数を確保
                       ↓ 上限未満のみ
                OpenAI画像加工 → PNGを返却
```

- Secrets Managerからサーバーの秘密情報を読み込みます。OpenAIキーとAWS資格情報はアプリに含めません。
- アプリ共有トークンは`X-DearMe-Token`。本公開デモでは意図的に公開しており、本人確認にはなりません。
- OACの署名はCloudFrontからLambdaへのアクセス用で、利用者認証ではありません。
- WAFは`POST /images/process`をIPごとに5分10リクエスト基準で制限。複数IPへの完全な対策や料金上限ではありません。
- Lambda予約同時実行数は5。1日5回という意味ではありません。
- DynamoDBは`GLOBAL#YYYY-MM-DD`（JST）をキーに、`used < 50`の場合だけ更新する原子的な条件付き更新で全体50回を制限します。
- 加工前の予約なので失敗時も返却しません。DynamoDBの確認不能時は503で止めます。TTLは古い項目の掃除専用で、日付リセットとは独立です。
- OpenAI SDKの自動リトライは無効。利用者の再送は新しい試行です。
- 本番のAPI説明ページは非公開。写真・メモ・部屋配置の保存先は端末内で、S3同期はありません。

## 残る制約

公開トークンを使った第三者による枠の消費は防げません。日次50回はAWSの通信・WAF等を含む金額上限ではありません。既存Lambdaには旧公開用の許可が残っているため、管理者による整理が必要です（現在のURL認証方式はAWS_IAM）。限定期間のデモとして運用し、終了時は失効・停止します。

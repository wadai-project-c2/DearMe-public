# コンペ終了後の手動停止（運営向け）

自動失効・自動停止は設定していません。以下は運営が権限を持つAWS環境で実施します。公開デモ利用者は実施不要です。

1. READMEに共有サービス終了を告知し、必要な運用記録を保存します。
2. Lambdaの予約同時実行数を0にして新しい画像加工を停止します。既に実行中の処理が終わるまで確認します。
3. Secrets Managerの共有アプリトークンを新しいランダム値へ置換します。空値にはしません。起動時キャッシュがあるため、将来再開する場合は実行環境が更新されるよう配備し直します。
4. OpenAI側で本デモ専用APIキーを失効します。他システムが使うキーの場合は影響を確認します。AWSのSecret削除だけではOpenAIキーは失効しません。
5. 復旧不要であることを確認後、CloudFrontを無効化して削除、WAF関連付け・Web ACL、OAC、Lambda URL/関数、専用DynamoDBテーブル、専用ログ・Secret・IAM権限を依存関係に沿って整理します。共用リソースは削除しません。
6. CloudFrontの無効化だけでは全リソースの課金は止まりません。CloudWatch、WAF、Secrets Manager、DynamoDBのバックアップ等も残存確認します。
7. 公開設定ファイルを無効な値に変更します。ただしGit履歴・既存クローンからは消えないため、サーバー側での失効が必須です。

Secretの削除には復旧待機期間を使用し、不要と確認した専用リソースだけを削除してください。削除前に対象名とARNを確認し、一括削除はしません。

# DearMe audio assets

音源は次のファイル名で配置してください。コード変更は不要です。

## BGM

- `bgm/home_bgm.mp3`: 「落ち着くジャズループ」（ユーザー提供）。アプリ全体で音量35%でループ再生され、画面を切り替えても続きます。設定からBGMを切り替えられ、バックグラウンドでは一時停止します。

iOSではambientカテゴリを使用し、端末のサイレントモードを尊重して他アプリの音声と混在させます。BGMの開始・一時停止・再開は直列化し、読み込み中の設定変更や素早いバックグラウンド往復でも最新の状態を反映します。実機のサイレント切替・他アプリ音声との共存は配布前に確認してください。

## 効果音

CREATE右上の音符から「サウンド設定」を開きます。BGMと演出・画面切替の効果音を個別に切り替えられます。既存の標準ボタン操作音は別系統で、端末のサイレント・操作音設定に従います。削除済みの「部屋について」画面は復活させません。

- `sfx/button_tap.mp3`: 汎用ボタン（将来の追加用）
- `sfx/navigation.mp3`: 下部ナビゲーション・ホーム復帰
- `sfx/processing_complete.mp3`: 写真・画像加工完了（将来の完了通知用）
- `sfx/swipe_placement.mp3`: 思い出を上へスワイプして配置
- `sfx/present_celebration.mp3`: アバターの喜び・プレゼント演出
- `sfx/save_complete.mp3`: 保存完了ポップアップ

MP3を推奨します。差し替え時は同名ファイルを置き、アプリを再ビルドして
ください。音源が存在しない間は該当音だけが無音になり、操作は継続します。

導入する各音源について、出典URL、作者、ライセンス、利用条件、取得日を
プロジェクトのライセンス資料へ記録してください。
